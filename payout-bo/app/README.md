# MaxPay BO — mock โอนออก

ไม่ใช่แอปโปรดักชัน ข้อมูลจำลองใน `src/mock/`

```
npm install
npm run dev
```

สูตรเงินและคิวอยู่ที่ `src/mock/query.ts` ห้ามย้ายไป JSX

มุมบนขวา: สลับแพลตฟอร์มแอดมิน / ร้าน Acme (DIRECT)  
แอดมินมีช่องเดโมแบนเนอร์บ้าน (send ปิด, ยอดเก่า, ไม่มีบัญชีต้นทาง, ยอดไม่พอคิว)  
ร้าน DIRECT ร้านเดียวเห็นการ์ดสมุด ใช้ได้ (`operate`) และกันไว้รอถอน (`pending_payout`)
