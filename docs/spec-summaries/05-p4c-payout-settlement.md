## เป้าหมาย

รวมรายการถอนเป็นชุด bulk ของกรุงไทย แต่ละใบปิดยอดแยกจากบันทึกของธนาคารเอง  
เมื่อจบ ร้านถอนได้โดยไม่มีคนในทาง และผลมาจากสถานะที่ธนาคารเก็บ ไม่ใช่แค่ “สายเรียกสำเร็จ”

## ทำอะไร

- รวมคิวถอนเป็นชุด ตามเวลาหรือจำนวน อย่างไหนถึงก่อน
- ตรวจชื่อผู้รับก่อนเปิดชุด บัญชีไม่มีตัว = ล้มรายการนั้นก่อนเข้าชุด
- ส่งชุดด้วย hook เดียวกับ P4b: บันทึกเลขออเดอร์ก่อนเงินขยับ
- ปิดยอดจาก endpoint รายการย่อยของธนาคารเท่านั้น
- ค่าธรรมเนียมโอนธนาคารลง `HOUSE_EXPENSE` บ้านเป็นคนจ่าย ไม่หักร้าน
- กู้ชุดที่สะดุด: ยังไม่มีเลขออเดอร์ = ส่งใหม่ได้ มีเลขแล้วห้ามส่งซ้ำ

## ไม่ทำอะไร

- ไม่มี webhook `processing` / จบรายการ (งานแยก)
- ไม่มีหน้าจอให้คนปิด `NEEDS_REVIEW`
- ไม่เปิดสวิตช์เงินเอง
- ไม่ลบออเดอร์ค้างที่ธนาคารเป็นชุด

## กฎเหล็ก

- ค่าบริการเกตเวย์ ≠ ค่าธรรมเนียมธนาคาร ห้ามปน
- ไม่เห็นเดบิต ≠ โอนไม่เกิด ห้ามปล่อยเงินที่กันไว้เพราะสเตตเมนต์เงียบ
- สถานะที่ไม่รู้จัก = `NEEDS_REVIEW` ห้ามปิดสำเร็จหรือล้มอัตโนมัติ
- อ่านสถานะจากหน้า detail ของรายการย่อย หน้า list ส่งคำคนละชุด (`รายการสำเร็จ` vs `SUCCESSFUL`)
- `isCompleted` ไม่ใช่สัญญาณว่าเงินถึง ห้ามอ่าน
- ดูยอดใช้ได้จาก `overview` ห้ามใช้ `cashflow` เพราะเป็นตัวเลขเก่า
- เมื่อมี `bank_bulk_order_id` แล้วห้ามส่งชุดนั้นซ้ำ

## เมื่อจบแล้วได้อะไร

ถอนถึงบัญชีปลายทางโดยไม่มีคนกด และปิดยอดจากรหัสสถานะของธนาคาร  
เส้นส่งเดี่ยวถูกลบได้ **หลัง** เส้นชุดขยับเงินจริงแล้วเท่านั้น ไม่ใช่งานแรกของเฟส
