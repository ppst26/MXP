# รูปแบบสรุป spec

ไฟล์สรุปทุกฉบับใช้โครงนี้ ไม่ใส่รายละเอียด implementation

| หัวข้อ | ใส่อะไร |
|---|---|
| เมตา | วันที่, สถานะ, ไฟล์ต้นฉบับ, ขั้นลำดับ |
| เป้าหมาย | หนึ่งย่อหน้า ว่าเฟสนี้มีไว้ทำอะไร |
| ทำอะไร | รายการสั้นๆ ที่อยู่ในขอบเขต |
| ไม่ทำอะไร | สิ่งที่ห้ามทำในเฟสนี้ |
| กฎเหล็ก | สิ่งที่ผิดแล้วเงินหายหรือจ่ายซ้ำ |
| เมื่อจบแล้วได้อะไร | สิ่งที่พิสูจน์ได้ |
| ขั้นถัดไป | เฟสถัดไปที่ต้องมีของนี้ก่อน |

ชื่อไฟล์เรียงตามลำดับทำงาน ไม่ใช่ตามวันที่ในชื่อสเปกอย่างเดียว
