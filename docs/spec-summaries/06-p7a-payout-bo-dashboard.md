## เป้าหมาย

ให้แอดมินเห็นว่าโอนออกยังไหลอยู่ไหม ต้นทุนธนาคารเท่าไหร่ ชุดไหนค้าง ใบไหนค้าง และร้านไหนทำให้ระบบสะดุด โดยไม่ต้องเปิดฐานข้อมูล

## ทำอะไร

- ไซด์บาร์ต้นไม้ **โอนออก** → ภาพรวม · รายการใบถอน · ชุดโอน (แอดมิน, หลังมีตารางชุด)
- ภาพรวมสามโซน: สุขภาพบัญชี · การ์ดคิวตอนนี้ · ยอดช่วงที่เลือก
- ตารางร้านที่ต้องดูบนภาพรวมเจ้าของ (สูงสุด 8 แถว เรียงเตือนก่อนยอด)
- รายการและรายละเอียดใบถอน ตัวเลือกร้านแบบค้นหา เลือกโหนดได้ทั้งสาย
- รายการและรายละเอียดชุดโอน แพลตฟอร์มแอดมินเท่านั้น
- ค่าโอนธนาคารเฟิร์สคลาส: ข้ามธนาคาร 5.00 ต่อใบ ในธนาคาร 0.00 ห้ามบวกกับค่าบริการร้าน

## ไม่ทำอะไร

- ไม่มีตารางรวมแถวใบกับแถวชุด
- ไม่มีหน้าจอฝาก / ปุ่มปิด `NEEDS_REVIEW` / ปุ่มส่งชุดซ้ำ / ปุ่มปรับสมุด
- ไม่มี websocket — โซน 2 poll 15 วินาที
- ไม่เปิดรับเงินเป็นลูกของโอนออก
- ยังไม่ทำจอภาพรวมระดับร้าน (ตัดจากจอเจ้าของหลังล็อกตารางร้านที่ต้องดู)

## กฎเหล็ก

- โซน 2 = สแนปชอตคิว ณ ตอนนี้ ไม่ตัดวันที่ที่เลือก โซน 3 = รายงานตาม `created_at`
- ค่าบริการเกตเวย์ ≠ ค่าธรรมเนียมธนาคาร ห้ามปน
- ค่าโอนคิดต่อใบ ไม่ต่อชุด มี `bank_bulk_order_id` แล้วห้ามมี UI ส่งซ้ำ
- ชุด `FAILED` ไม่ทำให้ใบเป็น `FAILED`
- ร้านไม่เห็นหน้าชุด ยอดบัญชี บจก. ต้นทุนธนาคารทั้งระบบ และตารางร้านที่ต้องดู
- หน้ารายละเอียดไม่อยู่ในไซด์บาร์ ไฮไลต์ซับเมนูแม่

## เมื่อจบแล้วได้อะไร

เปิดกะแล้วรู้ว่าบัญชีจ่ายได้ไหม มีของค้างไหม ช่วงนี้สำเร็จ/ล้ม/ค่าโอนเท่าไหร่ ร้านไหนต้องดู แล้วเจาะลงใบหรือชุดได้โดยไม่ปนชนิดแถว
